# Respostas das atividades

## Atividade 1
O arquivo **index.html** serve para criar a página na linguagem de marcação HTML. O **style.css** tem como função ser a estilização do conteúdo dentro do **index.html**.

## Atividade 2
O arquivo HTML deve começar com **DOCTYPE html** para inicializar a versão mais recente do HTMQL.

## Atividade 3
A tag responsável pelo titulo do site é *title*

## Atividade 4
h1 representa o título principal e o p representa o parágrafo.

## Atividade 5
section é a tag responsável semânticamente para abrir uma sessão.

## Atividade 6
nav é a tag responsável semânticamente para abrir um menu de links. Para os links utilizamos a e a href="" para linkar o destino do link.

## Atividade 7
Utilizamos o **id** para indentificar a section;
O valor do **href=""** deve ser **href="#sobre"**.

## Atividade 8
img é a tag para colocar imagens; img src="" para definir o caminho da imagem.

## Atividade 9
figure para agrupar a imagem e a legenda figcaption para apresentar a legenda.

## Atividade 10
Utiliza-se do atributo a href="URL" para definir o endereço de destino.

## Atividade 11
Um link interno tem como funcionalidade trocar entre páginas do mesmo site, já o link externo direciona o usuário a um endereço de fora do site.

## Atividade 12
A tag table representa a tabela; A tag tr representa a linha da tabela; A tag thead representa a célula do cabeçalho da tabela; A tag td representa uma célula comum de dados.

## Atividade 13
Utiliza-se a href="mailto:" antes do email para criar um link que redireciona à um aplicativo de enviar emails.

## Atividade 14
Utiliza-se a tag footer para criar a sessão do rodapé.

## Atividade 15
A tag link dentro do head do HTML é responsável por linkar documento externos; Para linkar o CSS externo utilizamos o atributo **rel="stylesheet"** link rel="stylesheet" href="nome.css".

## Atividade 16
Utiliza-se a propriedade **font-family: Arial;** para definir a fonte.

## Atividade 17
Para definir a cor de um texto usa a propriedade **color: ;** e para alinhar textos utiliza **text-align: ;**

## Atividade 18
Fazendo a divisão utilizando uma virgula para selecionar mais elementos
**h2, h3 {**
    **color: darkgreen;**
**}**

## Atividade 19
Para selecionar a classe no CSS colocamos o simbolo **.** e depois o **nome da classe**. Ex.: .destaque {}. Para definir a classe no HTML temos que utilizar o atributo p class="destaque" dentro de um elemento.

## Atividade 20
Utiliza o simbolo **#** e depois o **nome do ID** para selecionar os elementos com esse ID. Ex.: #sobre {}.

## Atividade 21
A propriedade **widht: ;** define a largura do elemento. Para ajustar automaticamente a altura utiliza a propriedade **height: auto;** como **auto**.

## Atividade 22
A propriedade **padding: ;** para criar espaçamento interno de um elemento.

## Atividade 23
A propriedade **margin: ;** é usada para dar espaçamento externo. **margin: 0 auto** é muito utilizado para centralizar um elemento horizontalmente.

## Atividade 24
A propriedade **float** permite que um elemento flutue para um dos lados; Para o elemento flutar para à esquerda utilizamos **float: left;**.

## Atividade 25
A propriedade **width** define a largura da tabela, **border-collapse** unifica as bordas e o **border** define a borda.

## Atividade 26
Para tirar o sublinhado utilizamos a propriedade **text-decoration: none;**.
